# 🖼️ 主稿 #1 配图清单（前 8 张具体制作建议）

> **目标**：让"小白也能 3 分钟看懂"——不靠文字靠图
> **统一风格**：浅色背景 + 关键色高亮（蓝/橙）+ 中性字体（思源黑体 / Inter）
> **尺寸**：知乎封面图建议 1200×800，主文配图建议 1080×720 或宽屏 1200×600

---

## 图 1：头图（封面）— 拖拽上传 → 出结果

**核心信息**：3 步：上传 → 查 → 写回

**制作建议**：
- 风格：扁平插画风，三个圆角卡片横向排列（上传 Excel / AI 查询 / 下载结果）
- 配色：主色 #2D7FF9（蓝），辅助 #FF8A3D（橙）
- 中间用箭头连接，**箭头要"动态感"**（虚线 + 流动光点）
- 底部加一行小字："零 SQL · 零开发 · 3 分钟出数据"

**工具推荐**：
- 🎨 **Figma**（最推荐）：矢量、易改、团队协作
- 🎨 **Canva**：模板多，小白友好
- 🎨 **即時設計**：国产免费 Figma 替代

---

## 图 2：3 次被拉黑（故事化）

**核心信息**：3 段并排的"聊天截图"梗图

**制作建议**：
- 风格：仿微信聊天截图（脱敏 + 加梗）
- 三张并排：
  - 左："在吗？能帮我导个表吗" → 对面沉默 4 小时
  - 中：凌晨 2 点发消息 → "睡了，明早再说"
  - 右：群里 @你 → "哥，这事本来就该有个系统解决"
- **关键**：第三张的回复用**红色高亮 + 放大**，作为"觉醒时刻"

**工具推荐**：
- 🎨 **微信对话生成器**（在线工具，免费）
- 🎨 Figma / Canva 手动排版（更可控）

---

## 图 3：3 人小组（团队 / 决定）

**核心信息**：业务 + 研发 + DBA 三人组，决定做这个产品

**制作建议**：
- 风格：扁平头像 + 三个圆圈 / 三人剪影
- 配上简单文字："业务 × 研发 × DBA = Excel Database Query"
- 下面一行小字："三个月后，第一个版本上线"

**工具推荐**：
- 🎨 **Figma**：圆形头像 + 文字
- 🎨 如果有真实合影就用真实合影（更有温度）

## 图 4：拖拽上传界面（产品截图）

**核心信息**：真实产品界面，拖拽上传 Excel 的区域

**制作建议**：
- 风格：产品真实截图 + 关键区域红色框标注
- 框内文字："把 Excel 拖到这里"
- 旁边加一个动图箭头（GIF）展示拖拽动作

**工具推荐**：
- 📸 **Snipaste** / **ShareX** 截产品图
- 🎨 **Figma** 加红框 + 文字标注

## 图 7：SQL 模板（代码截图）

**核心信息**：Jinja2 模板，按月分表自动展开

**制作建议**：
- 风格：代码编辑器截图（VSCode / 主题色）
- 关键代码：
  ```sql
  SELECT * FROM orders_{{ month }}
  UNION ALL
  SELECT * FROM orders_{{ month | default('202509') }}
  ```
- 旁边加注解："✨ 写一次，全年 12 个月自动展开"
- 用代码高亮（深色背景 + 关键字彩色）

**工具推荐**：
- 📸 **Carbon**（carbon.now.sh）→ 把代码生成漂亮图片
- 📸 **Polacode**（VSCode 插件）→ 截图代码

---

## 图 8：流程走势图（产品截图）

**核心信息**：横向节点状态（成功/失败/等待/执行中）

**制作建议**：
- 风格：流程图，5 个圆角节点横向排列
  - 节点 1：✅ 抽取数据
  - 节点 2：✅ 写入 Excel
  - 节点 3：✅ 发送邮件
  - 节点 4：✅ 监督者审核
  - 节点 5：✅ 流程完成
- 每个节点下方显示耗时
- 节点之间用带颜色的线连接（绿/红/黄）

**工具推荐**：
- 🎨 **Figma** 手动画（最灵活）
- 🎨 **ProcessOn** / **draw.io**（国产免费，流程图专用）
