## 🚀 完整发布流程（7 步走）

### Step 1：登录知乎创作中心
1. 打开 https://www.zhihu.com
2. 登录账号（**手机号 / 微信 / 邮箱** 都可以）
3. 右上角点头像 → **「创作中心」**（不是"创作首页"，是"创作中心"）

> 💡 **关键路径**：登录后，访问 https://zhuanlan.zhihu.com/write 直接进入写文章页面

---

### Step 2：进入"写文章"页面
1. 在创作中心左侧菜单找到「**内容管理**」→「**文章**」
2. 点击右上角「**写文章**」按钮
3. 看到编辑器界面

---

### Step 3：输入标题
- 标题框在最顶部
- 直接粘贴：**被开发拉黑 3 次后，我做了一套让业务同事自助取数的系统**
- 字数限制 50 字内 ✅

### Step 4：编辑正文（重点！）

> ⚠️ 知乎编辑器**默认是富文本模式**，但有 2 种编辑器选择：

#### 选项 A：富文本编辑器（默认，推荐新手）
- 操作类似 Word / 公众号
- 工具栏：**B 加粗 / I 斜体 / 标题 / 列表 / 引用 / 链接 / 图片 / 视频**
- 适合不熟悉 Markdown 的用户

#### 选项 B：Markdown 编辑器（推荐）
- 切换方式：编辑器右上角「⚙️ 设置」→「Markdown 编辑器」
- 直接粘贴 `zhihu-article-1.md` 的 Markdown 原文即可
- **效果一致**，但要会基本 Markdown 语法

> 💡 **建议用 Markdown**——因为我们已经把全文写好了，直接复制粘贴最方便。
> 切换后，**正文框会变成纯文本框**，把 `zhihu-article-1.md` 的内容（不含头部"配套资源"部分）粘贴进去。

### Step 5：⭐ 插图操作（重点中的重点）

> 知乎编辑器**支持 3 种插图方式**，按推荐度排序：

#### 🏆 方式 1：从本地文件夹拖拽（最推荐，30 秒搞定）

```
操作步骤：
1. 打开 Windows 资源管理器（Win + E）
2. 导航到 E:\Desktop\workspace\excel-database-query\docs\images\
3. 选中第 1 张图（zhihu-cover-3step.png）
4. 按住鼠标左键，**直接拖到知乎正文框的对应位置**
5. 松开鼠标 → 图自动上传
6. 重复步骤 3-5，依次拖入所有图
```

**优势**：
- 不用上传到图床
- 不用先复制粘贴
- 一次拖一张，可控

**配图插入位置（按主稿 #1 顺序）**：

| 顺序 | 图片 | 文件 | 插入位置 |
|---|---|---|---|
| **图 1** | 头图（封面） | `zhihu-cover-3step.png` | **封面图位置**（见 Step 7） |
| **图 2** | 3 人小组 | `zhihu-team-3people.png` | "二、我们做了个决定"上方 |
| **图 3** | 流程走势图 | `zhihu-flow-chart.png` | "九、AI 模块预告"附近（彩蛋节） |
| 图 4-6 | 产品截图 | 你自己做 | "四、3 步上手"附近 |
| 图 7 | SQL 模板 | 你用 Carbon 截图 | "三、核心 3 招"中的 SQL 模板部分 |
| 图 8 | 聊天截图 | 你用微信生成器 | "一、3 次被拉黑"每段配一张 |

---

#### 方式 2：点击工具栏"图片"按钮上传

```
操作步骤：
1. 鼠标光标点到正文里要插图的位置
2. 点击工具栏的"图片"图标（🖼️ 图标）
3. 弹出文件选择窗口
4. 选择要上传的图片
5. 点击「打开」
6. 图片自动上传并插入到光标位置
```

**适用场景**：拖拽不方便时（触屏用户 / 远程桌面）

---

#### 方式 3：先复制图片，再粘贴

```
操作步骤：
1. 在 Windows 资源管理器中右键点击图片
2. 选择「复制」（或 Ctrl+C）
3. 回到知乎编辑器，光标点到插图位置
4. Ctrl+V 粘贴
5. 图片自动上传
```

**适用场景**：从其他位置（如微信、企业微信、聊天工具）复制图时

---

#### 插图后调整（让图更美观）

**调整大小**：
- 点击已插入的图片
- 拖拽图片边框的**小圆点**调整大小
- 知乎默认会限制最大宽度为正文宽
- 建议保持默认，**不要拉得太大**

**加图注**：
- 图片下方空一行
- 输入图注文字（建议用引用块或斜体）
- 例如：`*（图：拖拽上传 Excel → 自动查询 → 写回结果）*`

**调整位置**：
- 默认是**居中**
- 选中图片后，可以用工具栏的「左对齐 / 居中 / 右对齐」调整
- **建议全部居中**

---

#### 常见插图问题

| 问题 | 解决 |
|---|---|
| 图片上传失败 | 检查网络 + 图片大小（< 20MB）+ 格式（JPG/PNG/GIF） |
| 图片太大不清晰 | 知乎会自动压缩，建议 1080-2160 宽度的图 |
| 图片太小看不清 | 上传前先用工具放大到 2K（不用 4K，知乎会压缩） |
| 拖拽没反应 | 浏览器可能拦截，换成"点击工具栏上传"方式 |
| 图加载很慢 | 知乎服务器限流，分批上传（一图一传） |

### Step 7：设置封面图（影响打开率的关键）

> ⚠️ **封面图设置**很多人忽略，但它直接影响文章在信息流的打开率！

```
操作步骤：
1. 在编辑页面右侧找到「封面设置」或「文章设置」
2. 点击「设置封面」或「上传封面图」
3. 拖入「图 1 头图」(zhihu-cover-3step.png)
4. 系统会自动按 16:9 比例裁剪（你的头图就是 16:9，完美适配）
5. 点击确认
```

**为什么封面图很重要**：
- 知乎信息流里，**封面图占视觉 70%** 的注意力
- 一张好看的封面图 = 3-5 倍点击率
- 我们的 `zhihu-cover-3step.png` 正是为此设计

## ❓ 常见问题 FAQ

### Q1：发布按钮是灰色点不动？
**原因**：标题字数超限（>50 字）或正文为空
**解决**：检查标题字数 + 确认正文有内容

### Q2：发布后立刻看不到自己的文章？
**原因**：知乎有审核延迟（5-30 分钟）
**解决**：等 30 分钟再看，不要重复发布

### Q3：图片上传后不显示？
**原因**：图片格式不支持 / 大小超限 / 网络问题
**解决**：转成 JPG / PNG，控制 < 20MB

### Q4：草稿箱在哪？
**位置**：创作中心 → 内容管理 → 文章 → 草稿箱
**注意**：草稿箱里的文章可以随时编辑

### Q5：可以修改已发布的文章吗？
**答案**：✅ 可以！进入文章页面 → 右上角「编辑」按钮
**注意**：标题修改后，**推荐流量会重新计算**（短期降权）

### Q6：发布后能删除吗？
**答案**：✅ 可以，但**会大幅降权**（知乎不喜欢删稿）
**建议**：发布前用「预览」仔细看，别发布再删

### Q7：怎么让更多人看到我的文章？
**关键动作**（按效果排序）：
1. **种子评论**（黄金 30 分钟）
2. **朋友圈 / 群分享**
3. **回答相关问题**（在别人的问题下放链接）
4. **多发回答**（积累账号权重）
5. **付费知+**（后期再加码）
