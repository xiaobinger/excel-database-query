## ✨ 它是什么？

一个**基于 Flask + Vue3** 的企业级数据库查询与导出平台。

说人话就是：**你给它一个 Excel，它帮你从数据库里把数据查出来，再原样还给你。中间不用你写一行 SQL。**

支持 MySQL、PostgreSQL、SQL Server、MariaDB，内置 SSH 隧道，连生产库都能安全访问。

## 🎯 三大杀手锏，每一个都戳中痛点

### 🔥 杀手锏 1：上传 Excel，自动匹配，一键出结果

- 把 Excel 拖进来 → 系统**根据文件名智能推荐**查询选项
- 想偷懒？打开「**直通模式**」——上传即查、查完即下载
- 结果**自动写回 Excel 原位**，格式不乱、列对列
- 不会写 SQL？没关系——查询选项由管理员/开发**提前配好**，业务同事直接选

> 💡 **业务小白：从此告别"提数需求单"。**

### 🔥 杀手锏 2：SQL 模板，灵活又强大

支持 **Jinja2 语法**动态生成 SQL——

- 按月分表？`SELECT * FROM orders_{{ month }}` 自动展开
- 多表 UNION ALL？模板一配，全年数据一键汇总
- 列名同义词模糊匹配——「客户名」「客户姓名」「CustName」都能识别
- 大数据量自动分批执行，几十万行也不会卡死

> 复杂查询不用每次都找人写脚本，**配一次，受用一年**。

### 🔥 杀手锏 3：定时自动导出，邮件自动通知

- **Cron 定时**触发，每天/每周/每月自动跑任务
- 结果自动生成 Excel，**邮件直送到收件人邮箱**
- 配套**流程走势图**，节点状态一眼看清（成功/失败/等待/执行中）
- **失败即停 + 防重复执行**——金融级安全设计，资金场景也能用

## 🧩 一段彩蛋：把"写代码"变成"画流程图"的设计思路

> 这一节不是主菜，但是这套系统里**最值得借鉴的设计哲学**。

我们见过太多内部工具：业务一变，开发就要改代码；流程一改，测试就要重写。

Excel Database Query 想做点不一样的——**把业务流程"画"出来**。

🖱️ **拖拽即配置**
  - 步骤列表式编排，**拖一下就换顺序**
  - 每个节点独立配置：调什么接口、走什么通道、跑哪个环境，一目了然

🔀 **条件流转，不用 if-else**
  - 节点之间用「响应字段值」串起来：`等于 / 不等于 / 包含 / 大于 / 小于 / 成功 / 失败 / 在列表`
  - 支持**任意节点结果引用**（`nodeId.fieldName`），上一节点的输出直接喂给下一节点

🔁 **循环 + 多退出条件**
  - 节点可配置定时循环，**AND/OR 组合的退出条件**，满足即流转

📊 **横向流程走势图**
  - 节点状态横铺展示：成功 / 失败 / 等待 / 执行中，一眼看到卡在哪一步
  - 配套**每笔数据独立实例 + 节点日志**，排查问题不再靠"猜"

🛡️ **失败即停 + 防重复执行**
  - 节点失败 → 流程**立即停止**，不连带下一节点（资金场景刚需）
  - 三重防重：**状态检查 + 时间检查 + 运行记录检查**，同一行数据绝不被处理两次

🔔 **节点级通知 + 模板复用**
  - 每个节点可独立配失败通知、结束通知
  - 通知模板统一管理，**变量替换**全自动

> 💡 这套思路我们用在了**代付/支付编排**上，但你完全可以拿它去做：订单履约、对账流程、工单流转、数据同步、审批链…… 任何"多步骤 + 有条件 + 要可观测"的业务场景。
>
> **业务怎么变，拖一下就跟上**——这才是企业级工具该有的样子。

### Step 1️⃣：管理员配置查询选项
> 在网页上点几下，选表、写 SQL（或用模板）、保存。

> 系统自动跑查询，结果写回 Excel，下载即可。

> ✅ 整个过程**零代码、零 SQL、零等待**。
