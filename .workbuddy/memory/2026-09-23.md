### 踩坑
- CSS 注释里写 `mood-*/working` 会导致 `*/` 提前闭合注释 → lightningcss 报 "combinator" 解析错误，构建失败。
- 该工作区 frontend 是 ESM（package.json type:module），node 脚本需用 `.cjs` 后缀。
- managed node 22 跑 vite 有问题，用系统 node（D:\nodejs\node.exe）构建正常。
- playwright-cli 浏览器会话随单条命令结束回收，`open`/`resize`/`screenshot` 必须串在同一条 `&&` 命令里；file:// 截图异常，需起本地 HTTP 服务；`--filename` 相对路径存到 npx 工作目录（项目根），建议用绝对路径。
- SVG+DOM 双层宠物：DOM 表情层坐标必须按 SVG viewBox 实际五官位置校准（猫眼初版 y=41 贴耳根被吐槽"眼睛长耳朵上"，下移+内收到 y=45/间距16px 才正常）。改完务必用 gen-pet-preview.cjs + playwright 截图肉眼验证。
- 兔子重画（用户反馈"不像兔子"）：原问题=大圆球头+细天线耳+脸颊瘤+悬空门牙。改法=上窄下宽头型 path、宽厚耳、浅色吻部椭圆、粉鼻+人中、门牙紧挨 DOM 嘴弧线下沿（y 66.5，像从嘴里露出）、SVG 不画嘴弧线避免与 DOM 嘴双线。验证图 bunny-fix.png。
- 兔子二次重画（用户仍不满"外星兔子"）：教训是**小缩略图会掩盖比例问题，必须 5 倍单宠大图验收**。终版：耳朵用 ellipse（rx6.5 ry16 ±8° 外撇）保证饱满香肠形、双球吻部 circle(26/38,61,r7)、眼睛 9px、眼 top 按 mood-happy 全局 `top:12px !important` 基准定为 12.5 防表情切换跳位。gen-pet-preview.cjs 已加 `--only/--scale/--cols` 参数。验证图 bunny-v2.png。
- pet-moods.css 眼部机制：8 个实心点眼宠物 = 白眼底(.eye background 被覆盖为白) + ::before 58% 黑瞳 + ::after 30% 高光；frog/panda 自带眼白结构只补高光。mood-happy 强制所有眼 `top:12px !important` —— 新宠物眼睛 top 必须以 12px 为设计基准。
- 兔牙修复（"笑的时候牙不能跑到嘴外面"）：牙从 SVG 移到 DOM `.bunny-mouth::after`，跟随表情嘴型联动——normal 贴弧线下沿、happy 收进嘴盒内上部（top:0, 60%×46% 白牙垂入黑口腔）、curious/sneaky/proud/excited/dizzy 隐藏（proud 嘴自带 box-shadow 白牙）。原则：**凡与嘴型联动的部件必须挂在 DOM 嘴元素上（::after），不能放 SVG 固定坐标**。pet-moods.css 各表情嘴型速查：happy 填充∪10x6 / curious O嘴5x5 / sneaky 旋转坏笑8x4 / proud 咧嘴12x7(自带牙) / excited O嘴7x8 / dizzy 波浪10x3 / sleepy、alert 不变。
